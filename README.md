## ✨ Overview

A high-performance, immersive portfolio website featuring a **Cyber-Noir** aesthetic, **Neural Network** background animations, and strict **Brutalist** design principles. Built for speed, interactivity, and visual impact.

## 🚀 Key Features

- **🕸️ Neural Network Background**: Interactive Canvas-based animation with 80+ nodes and mouse-reactive connections.
- **🧊 3D Elements**: Custom 3D Logo and perspective-based hero section.
- **⬛ Brutalist Design**: Sharp edges, monochrome color palette, and terminal-inspired typography.
- **⚡ Performance**: Built with Vite for instant loading and optimized assets.
- **🖱️ Custom Cursors**: Dynamic cursor system with trails (optional).
- **🎮 Easter Eggs**: Hidden interactions including:
  - **Matrix Mode**: Triple-click the background.
  - **Konami Code**: `↑ ↑ ↓ ↓ ← → ← → B A`
  - **Secret Messages**: Try hovering the logo or double-clicking projects!

## 🛠️ Tech Stack

- **Frontend**: React + TypeScript
- **Styling**: Tailwind CSS + Custom CSS (Sharp Edges)
- **Animation**: Framer Motion + HTML5 Canvas
- **Routing**: Wouter
- **Icons**: Lucide React
- **Fonts**: Inter & JetBrains Mono

## 📦 Installation

Clone the repository and install dependencies:

```bash
# Clone the repository
git clone https://github.com/vishva2410/Person-Portfolio-Website-3.0-.git

# Navigate to the project directory
cd Person-Portfolio-Website-3.0-

# Install dependencies
npm install
```

## 🖥️ Usage

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## 📂 Project Structure

```
src/
├── components/       # Reusable UI components (NeuralNetwork, Logo3D, etc.)
├── pages/            # Main route pages (Home, About, Projects, etc.)
├── assets/           # Static assets
└── index.css         # Global styles & tailwind directives
```

## 🎨 Theme & Design

The design philosophy follows a **"Function/Over/Form"** approach with a **Cyber-Noir** twist:
- **Colors**: `#0a0a0a` (Background), `#e5e5e5` (Text), `#66FCF1` (Accents).
- **Typography**: `Inter` for UI, `JetBrains Mono` for code/data.
- **Interaction**: Everything reacts to user input.
